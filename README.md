DealLedger: a static Black Friday 2026 deal finder with 12 hand-checked deals. Every card shows the product, store, store link, sale price, usual price, computed discount, check time, where the price was read, and an honest verdict (true low, strong price, routine or repeated sale, inflated usual) with its evidence. Search plus category, store, and minimum-discount filters and four sort orders work offline on desktop and phone.

## Run it

```sh
node serve.ts
# open http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
